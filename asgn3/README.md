### Controls:
        | key | action |
        |-----|--------|
        | Shift + LeftClick | Lock cursor for better mouse controls |
        | ESC (while cursor locked) | Unlock cursor |
        | LeftClick (while cursor locked) | Remove the block in front of you |
        | Shift + RightClick | Ox bow animation from assignment 2 |

### Notes:
    - Added collision detection for walls and locked movement to XZ plane. 
    - Improved performance by using static buffers for vertices and UV coordinates.
